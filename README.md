# ⬆ GitHub Uploader — رافع الملفات إلى GitHub

تطبيق ويب محلي بواجهة عربية يتيح لك:

- **تسجيل دخول رسمي** إلى حسابك على GitHub عبر OAuth في متصفحك (بدون نسخ توكنات يدوياً)
- **عرض كل مستودعاتك ومشاريعك** أخضر/خاص مع بحث فوري
- **إنشاء مستودع جديد** (عام أو خاص) أو **اختيار مستودع موجود** للرفع
- **رفع أي شيء بأي صيغة**: ملفات متعددة 📄، مجلد كامل بكل فروعه 📂، أو أرشيف zip 🗜 (مع خيار فك الضغط تلقائياً أو رفعه كما هو)
- رفع إلى **أي فرع** (يُنشأ تلقائياً) وإلى **أي مجلد فرعي** داخل المستودع
- التزامات (Commits) منظمة: ملفات كبيرة تُقسّم تلقائياً إلى عدة التزامات، والملفات الثنائية تُرفع بأمان (Base64)
- ي تجاهَل تلقائياً ملفات النظام غير المرغوبة: `.git`، `__MACOSX`، `.DS_Store`، `Thumbs.db`

## ⚡ التشغيل

### أول مرة: أنشئ OAuth App في حسابك (إعداد لمرة واحدة)

1. افتح <https://github.com/settings/developers> ثم **New OAuth App**
2. املأ الحقول:
   - **Application name**: `GitHub Uploader`
   - **Homepage URL**: `http://localhost:5000`
   - **Authorization callback URL**: `http://localhost:5000/callback`
3. اضغط **Register application** ثم انسخ **Client ID**
4. اضغط **Generate a new client secret** وانسخ الـ **Client Secret**
5. شغّل التطبيق والصق القيمتين في صفحة الإعداد الأولى (تُحفظ محلياً على جهازك فقط)

> يمكنك تغيير المنفذ من الخطوة 1 ببدء التشغيل بأمر مثل `PORT=8080 python app.py` — عندها استخدم نفس المنفذ في callback URL.

### التثبيتل وتشغيل التطبيق

**Windows** — انقر نقراً مزدوجاً على `run.bat`، أو من CMD:

```bat
pip install -r requirements.txt
python app.py
```

**Linux / macOS**:

```bash
./run.sh
# أو:
pip install -r requirements.txt
python app.py
```

سيُفتح المتصفح تلقائياً على <http://localhost:5000>.
اضغط **🔐 تسجيل الدخول عبر GitHub**، وافق على الصلاحيات، ثم تظهر لك لوحة المستودعات.

## 📦 كيف ترفع ملفات؟

1. من قائمة **مستودعاتك** اضغط زر **اختيار للرفع ⬆** على المستودع المطلوب، أو أنشئ مستودعاً جديداً من النموذج أعلاه
2. في قسم **رفع ملفات**، اختر واحدة أو أكثر من:
   - أي ملفات (يمكن تحديد عدة ملفات معاً بأي صيغة: exe، صور، pdf، فيديو...)
   - مجلد كامل (يُحفظ هيكل المجلد والمجلدات الفرعية)
   - ملف zip (اختر: فك الضغط أو رفعه كما هو)
3. اختيارياً: حدد **الفرع**، **مجلداً فرعياً** داخل المستودع، و**رسالة الالتزام**
4. اضغط **⬆ ارفع إلى المستودع** وسيظهر شريط التقدم وتقرير النتيجة بكل ملف (ناجح/فشل)

## ⚠️ حدود GitHub

- الحد الأقصى لحجم الملف الواحد عبر API هو **100 ميجابايت** (أضع من يتجاوز ذلك في قائمة الفشل)
- محتوى الـ zip المفكوك محدود بـ 800 ميجابايت لكل أرشيف
- كل شيء يعمل محلياً: التوكن لا يُرسل لأي جهة غير github.com مباشرة
